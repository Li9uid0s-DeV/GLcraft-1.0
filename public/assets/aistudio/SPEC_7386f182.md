# マイクラ風ボクセルゲーム「本家レベル化」統合仕様書（AI Studio の Gemini に渡す用）

> **目的**: ブラウザで動くマイクラ風ボクセルゲームを「本家（Minecraft Java 版）と同じレベルの見た目・動き・手触り」に引き上げるための統合仕様。対象は AI Studio で開発中の既存ゲームへの追加実装。§1〜§3 が土台、§4〜§5 がキャラクター／敵モブ／アニメーション（今回の主役）、§6 が ProtoManly's Weather 式の天気、§7 が Distant Horizons 式の遠景 LOD。
>
> **大原則（絶対に守ること）**
> 1. **本家のアセット（テクスチャ・モデル・音源）を抜き出して使わない。** 本家の「仕様」（寸法・UV配置・アニメーションの方式）は再現してよいが、ドット絵そのものは同仕様で**自作**する。流用は著作権侵害になり、公開もできない。
> 2. テクスチャは画像ファイルではなく、**Canvas にピクセルを打つ生成コード**として実装する（パレット＋部位ごとの塗り規則をコードで定義）。AI Studio のテキスト開発フローで再現可能にするため。
> 3. 性能予算を超えない：モブ同時存在は最大24体、パーティクルは常時2,000個以下、チャンクメッシュ生成はメインスレッドを塞がない（Worker か分割処理）。スマホブラウザで 30fps を割らないことを優先し、見た目の豪華さは設定で落とせるようにする。

## 1. 土台：見た目の最低ライン

- **テクスチャアトラス**: 1ブロック面 = 16×16 ドット。全ブロック分を1枚のアトラスにまとめ、UV で切り分ける（draw call 削減と「ドット絵の統一感」の両立）。単色ベタ塗りは禁止。
- **ライティング**: 太陽光＋ブロック光源の flood fill 伝播（0〜15段階）。洞窟が自然に暗くなり、置いた光源が周囲を照らすこと。
- **頂点 AO**: ブロックの角に隣接ブロックに応じた陰影を頂点色で焼く。スムーズライティング（面の継ぎ目で光量を補間）。
- **地形**: ノイズ生成の無限チャンク、バイオーム（平原/砂漠/雪原/森林）、木・鉱石・簡易洞窟、シード再現性。
- **描画**: 面カリング済みチャンクメッシュ、視錐カリング、編集チャンクのみ再メッシュ。

## 2. モデル共通仕様（本家方式の再現）

本家のキャラは全て「**UV 付き直方体の組み合わせ＋ピボット回転**」。この方式をそのまま採用する。これにより本家と同種の動きが低コストで再現できる。

- 単位: 16px = 1ブロック。モデル座標は px 単位で定義し、描画時に /16 する。
- 各パーツは `BoxGeometry` 相当＋部位別 UV（テクスチャシート上の矩形割り当て）。
- 各パーツは**ピボット（回転中心）**を持つ。例：腕は肩、脚は股関節、頭は首。ピボット位置を間違えると動きが即「パチモン」になるので寸法表の数値を厳守。
- 全パーツは1つのグループ（ルート）にぶら下げ、ルートごと移動・回転・被弾ティント（全パーツ赤色乗算）を適用できる構造にする。

## 3. プレイヤーキャラクター

### 3.1 モデル寸法（本家準拠）

| パーツ | サイズ (W×H×D px) | ピボット | 備考 |
|---|---|---|---|
| 頭 | 8×8×8 | 首元（胴の上端） | かぶり物レイヤー用に 8.5 一回り大きい外殻も用意（任意） |
| 胴 | 8×12×4 | 腰（下端） | |
| 腕（左右） | 4×12×4 | 肩（上端） | |
| 脚（左右） | 4×12×4 | 股関節（上端） | |

- モデル全高 32px（=2ブロック）、当たり判定は高さ1.8・幅0.6ブロック。
- 一人称では腕のみ別描画（自分の腕が見える）。三人称／他者表示では全身。

### 3.2 スキンテクスチャ

- **64×64 レイアウト（本家の現行スキン形式と互換配置）** で自作ドット絵を描く。互換配置にする理由は、将来ユーザーが自作スキンを差し替えやすくするため。各部位の UV 矩形は本家形式に一致させる。
- 既定スキンは「服・髪・肌・靴」の色分けが分かる無難なデザインを Canvas コードで生成。ランダムなベタ塗りではなく、部位ごとに陰影（下端を暗く等）を持たせる。

### 3.3 アニメーション（手続き、補間必須）

本家のアニメーションは全て数式と補間。以下を `walkCycle` 位相と状態で駆動する：

| モーション | 実装 |
|---|---|
| 歩行 | 脚と腕を sin 波で逆位相スイング（脚L = sin(t)、脚R = sin(t+π)、腕は脚と逆）。振幅と周波数は移動速度に比例 |
| 走行（スプリント） | 振幅増＋体をわずかに前傾＋視野角が少し広がる |
| 静止 | 腕の微かな揺れ（呼吸）だけ。完全静止はさせない |
| ジャンプ/落下 | 脚を軽く開き、腕が少し上がる。落下速度が大きいほど腕が上がる |
| 泳ぎ | 腕を交互に掻く、体は水平気味 |
| 攻撃/掘る | 利き腕を約0.3秒で振り下ろす（イージング付き）。連打時はアニメを頭出しで再開 |
| アイテム所持 | 利き腕が少し曲がったまま固定 |
| 頭と体の向き | 頭は視線方向に即追従、体（胴以下）は遅れて lerp で追従。真横を向いた時だけ体が回る「本家っぽさ」の肝 |
| 被弾 | 全パーツ赤ティント 0.2秒＋ノックバック |
| 死亡 | 全身が横に倒れる（ルート回転 -90°へ 0.2秒）＋赤ティント、煙パーティクルで消滅 |

- 全ての角度は直接代入せず **lerp（指数補間）** で目標角に寄せる。カクつきは「本家レベルでない」一番のサイン。

## 4. 敵モブ共通仕様

### 4.1 AI（ステートマシン）

状態: `待機（徘徊）→ 索敵 → 追跡 → 攻撃 → 被弾 → 死亡`。

- **索敵**: プレイヤーとの距離16ブロック以内＋視線（簡易：遮蔽チェックは地形レイキャスト1本）で追跡開始。音でも気付く（任意）。
- **移動**: 地面に沿った直進ステアリング＋1段差は自動でジャンプ、落下しそうな崖では止まる（簡易チェック）。本家の経路探索も大雑把なので、この精度で「らしい」動きになる。完全な A* は不要。
- **攻撃**: 接触距離で攻撃モーション＋クールダウン（約1秒）。ノックバック付き。
- **被弾**: 赤ティント＋ノックバック＋短い硬直。HP が尽きたら死亡モーション→ドロップアイテムをポップ→消滅。
- **スポーン**: 暗い場所（光量が低い）＋夜に、地表/洞窟へ。プレイヤーから24ブロック以上離れた場所のみ。同時上限24体。64ブロック以上離れたらデスポーン。
- **「らしさ」ルール**: ゾンビ型・スケルトン型は日光で燃える（炎パーティクル＋継続ダメージ）。これだけで本家感が跳ね上がる。

### 4.2 個別モブ

**(a) ゾンビ型（基本の敵）**
- モデル: プレイヤーと同一リグ（頭8×8×8、胴8×12×4、腕4×12×4、脚4×12×4）。**腕は前方に水平に伸ばしたまま**（本家の象徴的ポーズ）。
- テクスチャ: 64×64、自作。緑系の肌＋ボロ服の色分け。
- 挙動: ゆっくり直進追跡、腕伸ばし歩行アニメ（脚だけ sin スイング、腕は固定＋微揺れ）。接触で殴打。
- 昼間は燃える。

**(b) スケルトン型（遠距離）**
- モデル: 人型リグだが腕・脚を細く（幅2px級）、肋骨感のある胴テクスチャ。64×32 テクスチャ自作、白〜灰のパレット。
- 挙動: プレイヤーと距離を取る（近づかれたら下がる）。弓を引くモーション（両腕で構えて 0.8秒チャージ）→矢を発射（放物線の飛翔体＋当たるとダメージ）。
- 昼間は燃える。

**(c) クモ型（高速・壁）**
- モデル: 頭＋胴の2節（横幅大）、脚8本（左右4本ずつ、斜めに張り出す）。64×32 テクスチャ自作、暗色＋赤い目（複数ドット）。
- 挙動: 移動が速く、脚は位相をずらした小刻みスイング。ジャンプで襲いかかる。壁登りは省略可（段差ジャンプで代替）。
- 昼間は燃えない（本家準拠で中立化してもよいが、簡易版では敵対のままで可）。

**(d) 爆発型（クリーパー風・自作デザイン）**
- モデル: 頭8×8×8、縦長の胴、短い脚4本、腕なし。緑の迷彩風ドット絵は自作パターンで（本家の顔ドット配置をそのまま写さない）。
- 挙動: 静かに接近→射程内で停止して **点滅（白フラッシュ）＋膨張（スケール1.0→1.25）約1.5秒** →爆発（地形を球状に破壊＋範囲ダメージ＋爆発パーティクルと音）。途中で距離を取れば点滅が止んで解除。
- この「溜め→爆発」の緊張感が本家の看板なので、点滅と膨張と効果音のタイミングを厳密に。

### 4.3 モブのテクスチャ生成

- 全モブ、§3.2 と同じく Canvas ピクセル生成コードで自作。パレット（基調色3〜4色＋陰影色）をモブごとに定義し、部位ごとに「上面は明るく、側面は中間、下面は暗く」の立体感ルールを適用。
- 目・口などの顔パーツはモブの個性が出る場所なので、ランダム配置ではなく座標指定で描く。

## 5. エフェクト・音（モブとセットで効く）

- 被弾時の赤フラッシュ、死亡時の煙、爆発の破片＋衝撃の画面揺れ（小）。
- 足音・被弾音・死亡音・爆発音は WebAudio の簡易合成（ノイズ＋減衰）でよい。録音素材の流用はしない。
- 矢や破片などの飛翔体は使い回しプールで管理（生成/破棄を繰り返さない）。

## 6. 天気：ProtoManly's Weather 式

本家 Mod（Minecraft Java 版）の本質は「雨」ではなく「**育って移動する嵐セル**」と「**接地して地形を壊す竜巻**」。以下の3段階で実装する。

### Phase 1：嵐セルと空
- 嵐セル = `{位置, 半径, 強さ0〜1, 段階（発生/成熟/衰退）, 移動ベクトル, 寿命}`。プレイヤーから離れて湧き、風向に流れ、寿命で消える。現在の天気は最も近いセルの強さで決まる。
- 雲：本物のレイマーチングはスマホで重すぎるため代替実装。ノイズテクスチャの雲レイヤー2〜3枚をスクロール＋成熟セルの上に回転する円盤状の嵐雲メッシュ。強さで雲色を白→灰→黒へ補間、空とフォグも連動。
- 雨：カメラ周囲のパーティクル。強さで量・風の斜め・音量が変わる。雪バイオームでは雪に切替。
- 雷：強さの高いセルでランダム落雷。ギザギザポリライン（中点変位生成）＋空フラッシュ＋距離で遅れる雷鳴。

### Phase 2：竜巻（見た目と風）
- 成熟セルが閾値を超えたら漏斗雲を生成：円錐メッシュ＋回転ノイズシェーダ、約10秒かけて降下。
- 接地で風フィールド有効化：周囲のパーティクルとプレイヤーに「中心方向の引力＋接線方向の回転力」。プレイヤーは引き寄せられ、視界は揺れる。
- 竜巻はセルの移動＋ランダムなふらつきで前進。同時1本まで。セル衰退とともに細って消滅。

### Phase 3：破壊とレーダー
- 破壊：半径内で「ブロック硬さ < 風の強さ」のブロックだけを、1ティック上限付きで破片エンティティ化して巻き上げる。硬いブロック（石・原木等）は強い竜巻でのみ。
- EF 表示：風速パラメータから EF0〜EF5 を算出し「竜巻接地：EF3」のように画面表示。
- レーダー：ミニマップにセルを色丸（緑→黄→赤）で表示。嵐を避ける/追う遊びを作る。
- 設定：発生率・最大強さ・**破壊ON/OFF** は必ず設定項目にする（建物を壊されたくないプレイヤー向け。本家 Mod でも賛否が分かれる点）。

## 7. 遠景：Distant Horizons 式 LOD

本家 Mod の仕組み（描画距離の外を低解像度で描き続ける）を3段で再現する：

| 距離 | 方式 |
|---|---|
| 近距離 | 通常チャンク（フル解像度メッシュ） |
| 中距離 | 2×2〜4×4 ダウンサンプルした粗いメッシュ |
| 遠距離 | 高さマップのみ：1列＝1本の柱、色は最上ブロックの平均色 |

- LOD データはチャンク生成時に同時生成して保存。ブロック編集時は該当範囲の LOD のみ再生成。
- 段の境界はフォグで馴染ませる（遠景ほどフォグ色に寄せる）。これで「地平線まで続く世界」の印象を作る。
- 目標：体感の視界 3〜4 倍。遠景は静的でよい（モブ・天気エフェクトは近距離のみ）。

## 8. 実装フェーズ順

1. **土台**（§1）：テクスチャアトラス、ライティング、AO、地形とメッシュ
2. **プレイヤー**（§3）：モデル＋スキン＋アニメーション一式
3. **モブ**（§4〜§5）：共通AI → ゾンビ型 → 爆発型 → スケルトン型 → クモ型 の順
4. **天気**（§6）：Phase 1 → 2 → 3
5. **LOD**（§7）：中距離 → 遠距離

## 9. 受け入れ基準（チェックリスト）

**キャラ/アニメ**
- [ ] 歩行時、腕と脚が逆位相で滑らかに揺れる（カクつきなし＝補間が効いている）
- [ ] 横を向くと頭が先に回り、体が遅れて付いてくる
- [ ] 攻撃/掘るモーションが約0.3秒で振り下ろされ、連打で詰まらない
- [ ] 被弾で赤く光り、死亡で倒れて煙になって消える

**モブ**
- [ ] ゾンビ型が腕を前に伸ばして追ってくる／昼に燃える
- [ ] 爆発型が点滅＋膨張してから爆発し、離れると解除される
- [ ] スケルトン型が距離を取りながら矢を撃つ
- [ ] モブが崖で止まる・1段差を登る・壁にめり込まない
- [ ] 同時24体でも 30fps を割らない（スマホ想定）

**天気/LOD**
- [ ] 嵐セルが発生→接近→消滅し、雲・雨・雷が強さに連動する
- [ ] 竜巻が接地して物とプレイヤーを引き寄せ、（破壊ON時）弱いブロックを巻き上げる
- [ ] レーダーに嵐が色付きで表示される
- [ ] 遠景がフォグと馴染み、地平線まで地形が続いて見える／LOD境界で露骨なポップインがない

**共通**
- [ ] 本家アセットの流用が一切ない（テクスチャは全て生成コード由来）
- [ ] 既存機能（破壊/設置/セーブ/地形生成）が壊れていない
